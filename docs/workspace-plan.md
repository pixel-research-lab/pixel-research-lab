# 픽셀 연구실 사용성 개선 계획

각 PR은 별도 브랜치와 체험실에서 확인한 뒤 병합한다. 번호는 이번 개선의 실행 순서다.

| PR | 사용자 요청 | 동작과 확인 기준 |
| --- | --- | --- |
| 1 | 2 · 스킬 수첩 | 꼭짓점에 사용자가 지정한 스킬 이름을 쓴다. 긴 이름은 두 줄과 전체 이름 목록을 사용한다. 스킬 1~2개는 기존 막대를 유지한다. |
| 1 | 3 · 출퇴근 기록 | 탁상시계에서 오늘의 출근·휴식·재개·퇴근, 날짜 선택, 최근 7일 합계를 연다. 과거 시각 수정과 누락된 퇴근 입력을 지원한다. 휴식은 합계에서 빼고 자정을 넘긴 연구는 날짜별로 나눈다. 미래 시각과 역순 입력은 그 자리에서 알려 준다. 수정이 다른 기기의 동작과 충돌하면 원래 순서를 보존하고 충돌 시각을 다시 고칠 수 있게 한다. |
| 1 | 4·5 · 화면과 버튼 | 넓은 화면에서 기존 좌우 여백의 약 60%를 남겨 연구실과 오른쪽 보드를 넓힌다. 모바일은 한 열로 읽는다. 복습 등록, 일일 문항 수 설정, 달력, 반려동물 선택을 버튼으로 구분한다. |
| 1 | 6 · 동료의 말, 7 · 전리품 | 자동 대사, 말풍선, 음성을 걷어내고 동료를 쓰다듬거나 바꿀 수 있다. 전리품 7종의 그림과 이름, 보유 상태를 공개한다. 보유한 전리품만 배치한다. |
| 2 | 1 · 퀘스트와 복습 편집기 | 데스크톱 작성 창은 900~1,000px, 모바일은 한 열로 만든다. 퀘스트 본문, 복습 질문, 복습 정답에서 문단 사이로 이미지를 드롭하거나 붙여넣고 그림 아래에서 계속 쓴다. 모바일은 파일 선택으로 같은 위치에 삽입한다. 그림을 옮기거나 지울 수 있고, 파일명은 숨기고 선택한 캡션을 표시한다. 코드 블록은 들여쓰기·줄바꿈과 Python·Bash·JSON 구문 색을 보존한다. PDF와 별도 자료 첨부도 지원한다. |
| 3 | 8 · 이사, 장비와 배치 | 숲속·온실·옥탑·한강뷰의 책상 폭·의자·기본 모니터를 방별로 설계한다. 이사 가격에 기본 가구를 포함한다. 추가 모니터·스피커·벽 달력·탁상시계 외형만 token으로 사고, 보유한 가구의 배치와 재배치는 무료다. 배치 모드에서 책상 위·벽 등 맞는 영역으로 이동하고 저장 또는 취소한다. 평소에는 시계·스피커·달력의 원래 동작을 사용한다. |
| 4 | 6 · 동료 행동 | 방별 책상 면과 빈 착지 위치를 PR 3에서 읽는다. 고양이는 올려다보기→도약→그루밍→낮잠, 강아지는 탐색→냄새 맡기→귀 세우기→쉬기처럼 종별 행동을 연결한다. 낮잠은 우선 1~3분, 눈·귀·호흡을 작게 움직인다. 움직임 줄이기 설정과 화면을 떠났을 때 애니메이션 정지를 유지한다. |

## 체험실 검증

- PR 1은 어제 퇴근을 18시에서 17시로 바꾸고 하루와 최근 7일 합계가 1시간씩 줄어드는지 확인한다. 브라우저를 다시 열어 수정한 기록을 확인한다. 휴대폰에서 날짜와 버튼을 터치하고 그래프와 전리품을 좌우 스크롤 없이 읽는다.
- PR 2는 기존 텍스트 카드를 열고, 새 카드에 문단→그림→캡션→코드를 입력해 맥에서 저장한 뒤 윈도우와 오프라인에서 다시 연다. 파일 원본은 기존 첨부 저장소에 두고 본문에 순서와 참조를 기록한다. 정답 공개 전에는 정답 본문·그림·캡션·코드를 모두 숨긴다. 백업 왕복과 업로드 재시도도 확인한다.
- PR 3은 이사 전 기본 가구를 미리 보고, 구매 후 장비를 옮긴다. 좌표와 외형을 방별로 저장해 다른 기기나 다른 화면 크기에서도 그림과 클릭 영역이 맞게 한다. 모니터 포스트잇도 함께 움직인다. 방을 다시 방문해 이전 배치와 token 잔액을 확인한다.
- PR 4는 고양이와 강아지의 바닥 이동, 책상 진입·휴식·이탈을 여러 차례 관찰하고 일곱 품종의 모습과 작은 화면에서의 겹침을 확인한다.
