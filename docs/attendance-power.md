# 출퇴근 전원 및 macOS Dock 점검 (2026-11-16)

## 동작

- 모니터, 추가 모니터, 노트북: 출근/연구 재개 시 켜짐, 퇴근 시 꺼짐.
- 잠시 비움: 출근 중인 상태로 유지해 화면과 야간 스탠드는 그대로 켜짐.
- 스탠드: 기존 달 표시와 같은 현지 시간 기준으로 18:00 이상 또는 06:00 미만이며 출근 중일 때만 켜짐. 낮에는 꺼짐.
- 시계, 창밖 풍경, 소통/음악/기록 바로가기는 계속 사용할 수 있음.
- 전원은 기존 출퇴근 기록에서 계산하므로 새 데이터나 마이그레이션이 없음. 기록 수정/동기화/오프라인 새로고침 후에도 같은 기준 적용.
- 홈, 꾸미기 미리보기, 배치 편집기가 같은 전원 상태를 사용함. 늦게 도착한 이미지의 재그리기도 출퇴근 상태를 유지함.

## Dock 조사

보고된 사진에는 고정 Chrome 아이콘 외에 여러 Chrome 아이콘이 있었다. 조사 당시에는 사용자 Chrome 본체가 하나만 실행 중이어서 과거 사진의 프로세스를 특정할 수는 없었다.

앱의 타이머와 Slack 알림 경로에서 Chrome 실행이나 자동 팝업 생성 코드는 발견하지 못했다. 한편 기존 개발 검증 명령은 `CHROME_BIN`으로 설치된 macOS Chrome 앱을 직접 실행했고, 각 테스트가 별도의 브라우저 프로세스를 만들 수 있었다. 이를 유력한 발생 경로로 보고 모든 Chromium 브라우저 테스트를 전용 headless shell로 통일했다. 이 조치는 테스트 중 일반 Chrome 앱이 추가 실행되는 경로를 제거한다. 사용 중인 Chrome 하나의 Dock 아이콘은 정상이며 웹앱에서 숨기는 대상이 아니다.

이번 검증에서 사용한 실행 파일은 `chromium_headless_shell-1234/.../chrome-headless-shell`이었다. 테스트 종료 후 이 테스트의 headless shell 프로세스는 남지 않았고, 기존 사용자 Chrome 본체는 계속 하나였다. 20분의 앱 시간을 전진시키는 동안 추가 탭/팝업도 발생하지 않았다. 이는 실제 시간을 오래 두고 관찰한 결과와 다르며, 이전 Dock 현상의 원인이 확정됐다는 뜻은 아니다. macOS의 최근 앱 표시나 개인 Chrome 설정은 변경하지 않았다.
