# 픽셀 연구실의 Slack 알림

웹앱의 컴퓨터에서 개인 바로가기를 추가하면 Slack 채널이나 카카오톡 오픈채팅을 바로 열 수 있습니다. Slack 알림을 받으려면 인터넷에 연결된 컴퓨터에서 아래 수신기를 실행하세요. Node.js 22.4 이상이 필요합니다.

1. 저장소 루트에서 `node slack-bridge/server.mjs`를 실행하고 터미널에 표시된 설정 주소를 엽니다.
2. Slack 채널 주소 `https://app.slack.com/client/T…/C…`에서 워크스페이스 ID와 공개 채널 ID를 복사합니다. **Slack에서 이 설정으로 앱 만들기**를 열고 올바른 워크스페이스를 확인합니다.
3. 생성한 앱의 **Install App**에서 설치한 다음 원하는 채널에서 앱을 추가합니다. 수신기 설정 창에 **Basic Information → App-Level Tokens**에서 발급한 `connections:write` 토큰과 **OAuth & Permissions**의 봇 토큰을 입력하고 **Slack 연결 확인**을 누릅니다.
4. 연구실 홈의 **알림 받기 → 수신기 연결**에서 설정 화면의 24자리 연결 코드를 한 번 입력합니다. 브라우저가 이 사이트의 로컬 네트워크 접근을 물으면 허용하세요. 설정 창은 닫아도 됩니다. 테스트할 때는 지정한 채널에 일반 글을 하나 올려 보세요. 모니터 불이 켜지고 소통 창에 알림이 표시됩니다. Slack 링크를 누르면 확인한 상태로 바뀝니다.
5. 개인 DM도 받으려면 앱 생성 전에 **내 개인 DM 알림도 받기**를 선택합니다. 기존 앱에는 수신기의 `/manifest-dm` 설정을 반영하고 Slack에서 재설치한 뒤 본인 사용자 토큰을 입력합니다. DM 발신자 확인에는 `im:history`, `im:read`, `users:read` 사용자 권한이 필요합니다.

수신기는 127.0.0.1에서 동작합니다. Slack 토큰은 해당 프로세스 메모리에만 보관하고 종료하면 지워집니다. 백그라운드 수신기가 실행 중이면 픽셀 연구실 탭 하나로 홈에서 알림을 받습니다. 탭을 다시 열면 자동으로 연결됩니다. 탭을 닫은 동안 브라우저 푸시는 보내지 않습니다. 연결 코드는 이 브라우저·계정에만 저장하며, **컴퓨터 → 이 브라우저 연결 끊기**로 지울 수 있습니다. 수신기 프로세스를 재시작하면 새 연결 코드를 입력해야 합니다. 수신기가 계속 실행되어 있는 동안 최근 80건을 메모리에 보관해 연구실을 다시 연결할 때 전달합니다. 알림으로 보관하는 내용은 채널·보낸 사람의 표시 이름, 시각, Slack 링크와 읽음 상태입니다. 메시지 본문은 저장하지 않습니다. 게스트 체험실 기록은 사용한 브라우저에 보관됩니다.

앱은 초대한 공개 채널의 일반 새 글을 표시합니다. 봇 게시물, 수정·삭제 및 채널의 스레드 답글은 건너뜁니다. DM은 본인과 상대방 사이의 대화에서 새로 받은 글에 한합니다. Slack의 앱 설치가 제한된 워크스페이스에서는 그 워크스페이스 관리자가 설치를 승인해야 합니다.
