# 픽셀 연구실

[연구실 열기](https://2e2guk.github.io/pixel-research-lab/)

논문이나 실험에서 떠오른 질문을 퀘스트로 등록하고, 예측과 관찰을 기록하면 스킬과 책상 장식을 얻는 픽셀 연구실입니다.

## 이전 데모에서 이사하기

기존 HTML 파일을 사용하던 브라우저에서 같은 파일을 열어 **세이브 관리 → 세이브 내보내기**를 누르세요. 웹앱에서 **세이브 관리 → 세이브 가져오기**로 JSON 파일을 고르고 퀘스트 수와 장식 순서를 확인한 뒤 적용하세요. 잘못 가져왔다면 **가져오기 전 상태 복원**을 선택하세요.

세이브에는 진행·완료 퀘스트, 작성 중인 예측·관찰, 아이템 수량과 세 자리의 배치가 들어 있습니다. 기록은 기기별 브라우저에 저장됩니다. 다른 기기에는 같은 메뉴로 세이브를 옮길 수 있습니다.

## 오프라인 사용

각 기기에서 온라인으로 한 번 접속해 화면 아래 **오프라인 준비 완료**를 확인하세요. 이후 같은 주소를 다시 열거나 설치된 웹앱을 실행하면 인터넷 없이 플레이할 수 있습니다. 책상 스피커는 온라인에서 YouTube 음악을 새 탭으로 엽니다.

## 로컬 실행 및 배포

저장소 최상위에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/`에 접속하세요. 웹앱 파일을 변경하면 `python3 tools/update-cache.py`를 실행해 오프라인 캐시 버전을 갱신하세요. GitHub Pages는 main 브랜치 최상위 폴더에서 배포합니다.
