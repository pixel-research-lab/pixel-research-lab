# 픽셀 연구실

[연구실 열기](https://2e2guk.github.io/pixel-research-lab/)

논문과 실험에서 떠오른 질문을 퀘스트로 만들고, 예측과 관찰을 기록하면 스킬과 책상 장식을 얻습니다.

## 맥과 윈도우에서 이어 하기

기존 기록이 있는 브라우저에서 **로그인 → Google로 로그인**을 선택하세요. 첫 연결 때 그 기기의 진행·완료 퀘스트, 장식과 책상 배치를 계정으로 옮깁니다. **동기화 완료**가 뜬 뒤 다른 기기에서 같은 Google 계정으로 접속하세요. 연결 전에도 로컬 연구실을 사용할 수 있습니다.

서로 다른 퀘스트와 책상 자리는 독립적으로 합칩니다. 같은 퀘스트는 더 진행한 단계가 우선이고, 같은 단계나 같은 자리를 양쪽에서 수정하면 마지막 편집이 남습니다. 같은 퀘스트로 두 번 보상을 받을 수 없습니다. 로그아웃하면 계정 화면을 닫습니다. 업로드를 기다리던 기록은 해당 기기에서 원래 계정으로 다시 로그인할 때 이어집니다.

새 브라우저 프로필은 새싹 화분 하나와 빈 퀘스트 목록으로 시작합니다. 로그인 전에는 같은 브라우저 프로필을 쓰는 사람이 로컬 기록을 함께 보게 됩니다. 로그인 후 연구실 기록은 Google 계정별로 분리됩니다.

## 출퇴근 기록과 탁상시계

작업 책상 아래 **연구 시작**을 누르세요. **잠시 비움**으로 시간을 멈추고 **연구 재개**로 이어갈 수 있습니다. **퇴근 · 저장**을 누르면 종료 시각을 기기에 저장하고 로그인한 계정에 동기화합니다. 탭을 닫아도 퇴근하기 전까지 연구 시간이 이어집니다. 자정을 넘기면 각 날짜에 해당하는 시간만 합산합니다. 최근 7일의 기록은 **연구 일지 → 출퇴근 기록**에서 볼 수 있습니다.

창밖 풍경과 탁상시계는 기기의 현지 시각을 따릅니다. 05–07시는 해돋이, 17–19시는 노을이고, 밤에는 달과 별이 뜨고 스탠드가 켜집니다.

## 오프라인과 백그라운드

기기마다 온라인으로 한 번 열고 화면 아래 **오프라인 준비 완료**를 확인하세요. 오프라인 편집은 기기의 IndexedDB에 기록됩니다. 다시 연결하거나 앱을 다시 열면 자동으로 동기화합니다. Background Sync를 지원하는 브라우저는 탭을 닫은 뒤에도 브라우저가 실행 기회를 줄 때 대기 기록을 전송합니다. Safari나 완전히 종료한 브라우저에서는 다음 실행을 이용하세요. 다른 기기로 바로 이어갈 때는 출발하는 기기에서 **동기화 완료**를 확인하세요.

기존 로컬 데모의 파일 백업은 **세이브 관리 → 세이브 내보내기 / 가져오기**에서 사용할 수 있습니다. 계정 로그인 상태에서 가져오면 기존 계정의 퀘스트와 합칩니다.

## 개발 및 배포

정적 파일과 번들이 저장소에 포함되어 있습니다. 저장소 최상위에서 `python3 -m http.server 8000`으로 로컬 웹앱을 실행할 수 있습니다. Firebase 로그인에는 프로젝트에 등록된 웹 도메인이 필요합니다.

동기화 소스는 `cloud/`에 있습니다. 변경 후 `cd cloud && npm ci && npm run build`를 실행하고, 저장소 최상위에서 `python3 tools/update-cache.py`를 실행하세요. GitHub Pages는 main 브랜치 최상위 폴더에서 배포합니다. Firestore의 계정별 접근 규칙은 `firestore.rules`입니다. 변경 시 `firebase deploy --only firestore:rules --project pixel-research-lab-2e2guk`로 배포하세요.

웹 방문은 Google Analytics 4의 페이지 조회로 집계됩니다. 앱은 퀘스트 내용, 연구 메모, 이메일, Firebase 사용자 ID를 방문 이벤트에 추가하지 않습니다.
